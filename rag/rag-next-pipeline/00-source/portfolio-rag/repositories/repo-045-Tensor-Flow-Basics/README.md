## What This Project Is

`Tensor-Flow-Basics` is a compact deep-learning learning repository organized around progressively richer TensorFlow/Keras exercises.

The repository contains four workstreams:

- `Basic Math Model`,
- `Fashion Classifier`,
- `CNN Number Recognition`,
- `Horse or Human`.

The progression moves from basic model construction to dense image classification and convolutional image classifiers.
