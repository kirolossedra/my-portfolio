## What This Repository Is

`Learning.English` is a version-controlled English-writing practice corpus.

Its structure is divided into two directories:

```text
WT1/
WT2/
```

The names and file contents correspond to two families of IELTS-style writing tasks.

`WT1` contains Task 1-style analytical writing exercises.

`WT2` contains Task 2-style essay exercises.

The repository records both the original prompts and written responses.

Many entries also preserve evaluation feedback beside the attempted response.

This makes the repository more than a folder of finished prose.

It records repeated practice, external assessment, corrections, and comparison between attempts.

## Repository Structure

The second writing-test directory contains day files extending through Day 11.

The files hold essay-style prompts and responses.

A representative Day 11 prompt asks the writer to evaluate whether unpaid community service should be compulsory in high-school programs.

The file then preserves structured feedback and a corrected-evaluation section.

## Task 1 Writing Practice

Task 1 files show a repeated workflow.

1. A quantitative prompt is preserved.
2. The data is represented in textual or Markdown-table form.
3. An answer is written in prose.
4. Evaluative feedback is stored beneath the answer.
5. In some files, additional trials are added for the same task.

This workflow supports comparison between attempts rather than treating each exercise as disposable.

### Quantitative Summarization

The Task 1 examples require extracting key features from structured data.

The writer identifies maxima, minima, trends, thresholds, and contrasts.

For example, one exercise compares household income groups with computer ownership percentages.

Another compares regional internet-user percentages and average internet speeds.

These exercises practice selecting salient facts rather than reproducing every input value.

### Comparative Language

The responses use comparative structures to describe:

- higher and lower values,
- regional dominance,
- world averages,
- gaps between categories,
- approximate shares,
- relative ranking.

The repository therefore evidences deliberate practice in data-driven explanatory writing.

### Multiple-Trial Structure

`WT1/day3.md` includes a clearly labeled `First Trial` and begins a `Second Trial` for the same prompt.

That structure is direct evidence of repetition and iteration.

The learner revisits the same source information instead of relying only on novel prompts.

## Task 2 Essay Practice

Task 2 files focus on argumentative and discursive writing.

The Day 11 example includes:

- a clear prompt,
- an introduction,
- discussion of competing positions,
- concrete examples,
- a conclusion,
- a request for rubric-based scoring.

The topics are broad social questions rather than technical exercises.

This requires the writer to organize a position across paragraphs and maintain argumentative coherence.

## Rubric-Based Feedback

The repository repeatedly stores writing evaluation under the same broad IELTS criteria.

Observed criteria include:

- Task Achievement or Task Response,
- Coherence and Cohesion,
- Lexical Resource,
- Grammatical Range and Accuracy.

The feedback often includes an overall band estimate.

Some entries also record a CEFR mapping.

This creates a semi-structured longitudinal evaluation format.

### Task Achievement

Feedback discusses whether the response addresses the prompt and highlights relevant information.

For Task 1 work, it comments on whether the response selected and compared the key features of the source data.

### Coherence and Cohesion

Feedback discusses paragraph organization, progression, linking devices, reference words, and repetition.

This gives the learner concrete signals about structural clarity.

### Lexical Resource

Feedback identifies vocabulary range, word choice, collocation, idiom use, and precision.

The examples distinguish vocabulary variety from contextual appropriateness.

### Grammatical Range and Accuracy

Feedback discusses sentence structures, punctuation, article use, word order, and grammar accuracy.

This supports targeted revision rather than only assigning a single total score.

## Corrected and Original-State Comparison

The Day 11 file contains a section labeled `After correcting mistakes`.

It records a criterion table and an overall evaluation for the corrected form.

The same file separately retains a `With Mistakes, and review` section.

This preservation of both states is significant.

The repository does not merely overwrite the weaker draft.

It keeps the learning trace.

A later reader can see the original expression, the evaluation, and the improved-state assessment together.

## Markdown as the Learning Medium

The repository uses Markdown as the storage format.

Prompts, prose responses, tables, headings, separators, criterion tables, and notes all live in text files.

This makes the practice history easy to diff and version.

It also lets one file combine:

- source task,
- response,
- evaluation,
- revised evaluation,
- notes,
- resource links.

The repository therefore demonstrates a lightweight version-controlled learning-journal workflow.
