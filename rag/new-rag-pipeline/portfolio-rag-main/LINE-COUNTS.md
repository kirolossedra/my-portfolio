## Chronology Note

Repository indices are persistent processing identifiers. Repository creation date is the canonical chronological sort key, which preserves correct historical ordering when earlier repositories are discovered during a later audit.

## Incremental Accounting Rule

For a new repository:

```text
new_cumulative_lines =
    previous_cumulative_lines
    + new_repository_readme_lines
```

For a revised repository:

```text
new_cumulative_lines =
    previous_cumulative_lines
    - old_repository_line_count
    + revised_repository_line_count
```
