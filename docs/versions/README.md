## Purpose

`docs/versions/` records **component versions, compatibility relationships and historical evolution** of the portfolio system.

<a id="what-belongs-here"></a>
## What Belongs Here

- component/schema/version maps;
- evolution chronology;
- active vs superseded version relationships;
- historical state transitions.

Deployment operating procedures and QC evidence belong in their dedicated folders rather than here.
