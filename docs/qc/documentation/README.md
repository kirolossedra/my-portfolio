## Purpose

`docs/qc/documentation/` contains Quality Control records about the documentation itself: preservation checks, link/taxonomy verification and evidence that a documentation reorganization retained substantive content.

<a id="what-belongs-here"></a>
## What Belongs Here

- preservation/integrity verification for documentation moves;
- link and navigation checks;
- documentation-structure acceptance evidence;
- historical verification outputs whose subject is documentation rather than RAG retrieval quality.

It does not contain RAG deployment decisions or RAG retrieval incidents.
